# UX audit — canonical rebuild

## Main route

Landing answers what RECODE is, why the action matters, what happens after the CTA and where data is stored. Onboarding remains three meaningfully bounded steps: consent/product boundary, origin, name/identity.

## Product shell

- Desktop: navigation rail retains all 11 destinations without presenting them as equal dashboard metrics.
- Mobile: five primary destinations are exposed (`Today`, `Story`, `Quests`, `Body`, `Profile`); six secondary destinations are grouped under `More`.
- Today leads with one story node and one real-world action before secondary stats.
- Story exposes speaker/location, scene text, 2–4 choices, requirements, cost, telegraph and real-action completion.
- Quests support complete/reduce/defer/replace/honest skip without deleting progress.
- Body loads the full 1,324 exercise catalog only when the feature is opened.
- Profile provides validated import, export, recovery notice, accessibility controls and delete confirmation.

## Safety and accessibility

The runtime keeps local-first copy, explicit health/medical boundaries, visible focus, semantic landmarks, reduced motion, high contrast, accessible icon labels and touch target rules. No new feature promises health sync or AI diagnosis.
