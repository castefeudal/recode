# Health Integrations

HealthDataProvider имеет Manual, Android Health Connect, iOS HealthKit, Desktop Cloud Sync и Mock реализации. Разрешения запрашиваются по категориям и не блокируют игру. Нативные bridge sources находятся в `native_plugins/`.

Garmin/Zepp подключаются через официальный API после получения credentials либо через CSV/JSON import. Рабочая интеграция без доступа не заявляется.
