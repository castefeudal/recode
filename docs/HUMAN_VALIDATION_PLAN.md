# Human validation plan — 7.0.0

## Minimum sample

- 8 first-time users: 4 RU, 4 EN; include two keyboard-only users;
- 4 accessibility sessions across NVDA, VoiceOver and TalkBack;
- 3 returning sessions after an intentional skipped day;
- 2 editors creating and re-importing a `.mmc` campaign.

## Tasks and success thresholds

| Task | Threshold |
|---|---:|
| Explain product after 15 seconds on landing | ≥7/8 mention choice + real action + consequence |
| Reach Today from fresh start | ≥7/8 without facilitator |
| Complete first choice/action/world arc | ≥7/8 under 7 minutes |
| Understand honest skip | ≥7/8 say progress is preserved |
| Export and restore save | 8/8 |
| AT completion of critical path | 4/4; no blocker |
| Creator export→CLI validate→import | 2/2 |

Capture time-on-task, misclicks, quote, severity, locale/device and consented
recording. A P0/P1 blocks launch; P2 requires owner disposition. Never label an
AI simulation or internal browser pass as human research.
