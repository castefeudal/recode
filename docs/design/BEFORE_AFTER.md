# Before / After

## Baseline characteristics

- Strong art and brand colour, but most visual decisions lived in one large global stylesheet.
- Limited semantic theme architecture.
- Text-symbol navigation and inconsistent control geometry.
- Landing, dashboard and story shared less compositional discipline than the product concept warranted.
- No reproducible screenshot evidence or design-system contract test.

## Final characteristics

- Layered semantic design system with dark, light and high-contrast foundations.
- Typed SVG iconography and reusable React primitives.
- Cinematic landing, editorial dashboard and split narrative scene.
- Dedicated mobile shell with bottom navigation and safe-area handling.
- Central motion, focus, target-size, typography, spacing, surface and status rules.
- Baseline/final Chromium evidence, SHA-256 lists, CSS parser audit, asset inventory and source-level design tests.
