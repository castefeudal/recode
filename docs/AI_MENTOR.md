# AI Mentor

AI — опциональная backend-функция. Клиентский ключ запрещён. Перед отправкой текста требуется отдельное согласие; health-данные требуют отдельного выбора. System contract: не ставить диагнозы, не назначать лекарства/фармакологию, не унижать, не обещать результат, предлагать одно конкретное следующее действие. Prompt injection не меняет эти правила. При ошибке используется deterministic fallback.
