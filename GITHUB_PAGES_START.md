# GitHub Pages deployment

1. Copy this package over the repository clone and commit to `main`.
2. In GitHub: Settings → Pages → Source = GitHub Actions.
3. Open Actions → Deploy site to GitHub Pages → Run workflow.
4. After success, open `https://castefeudal.github.io/recode/`.

This is a static deployment. The local/offline game works. The Python backend and server-side cloud sync are not hosted by GitHub Pages.
